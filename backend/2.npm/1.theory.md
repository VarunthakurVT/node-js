# NPM Commands Cheat Sheet

A quick reference for the most commonly used npm commands.

---

# 1. Initialization & Setup

These commands help set up a new project.

| Command | Description |
|---|---|
| `npm init` | Starts an interactive setup to create `package.json`. |
| `npm init -y` | Creates `package.json` instantly with default values. |
| `npm set init-author-name "Your Name"` | Sets a default author name for future npm projects. |
|  `npm config delete "init-author-name"` | this delete the author name|
---

# 2. Installing Packages

The core npm functionality: adding packages.

| Command | Description |
|---|---|
| `npm install` or `npm i` | Installs all dependencies from `package.json`. |
| `npm install <package>` | Installs a package as a dependency. |
| `npm install <package> -D` | Installs as a dev dependency. |
| `npm install <package> -g` | Installs globally. |
| `npm install <package>@version` | Installs a specific version. |
| `npm ci` | Clean install using `package-lock.json`. |

### Examples

```bash
npm install express
npm install nodemon -D
npm install typescript -g
npm install react@18.0.0
```

---

# 3. Managing & Updating Dependencies

Keep dependencies updated and clean.

| Command | Description |
|---|---|
| `npm uninstall <package>` | Removes a package. |
| `npm rm <package>` | Short form of uninstall. |
| `npm outdated` | Checks for package updates. |
| `npm update` | Updates all packages. |
| `npm update <package>` | Updates a specific package. |
| `npm prune` | Removes unused packages. |

### Examples

```bash
npm uninstall express
npm outdated
npm update
npm prune
```

---

# 4. Executing Scripts

Run project scripts.

| Command | Description |
|---|---|
| `npm run <script>` | Runs a custom script. |
| `npm start` | Runs the start script. |
| `npm test` | Runs the test script. |
| `npx <package>` | Runs a package without installing globally. |

### Examples

```bash
npm run dev
npm start
npm test
npx create-react-app my-app
```

---

# 5. Information & Debugging

Useful for checking project status.

| Command | Description |
|---|---|
| `npm list` | Shows installed packages. |
| `npm list -g --depth=0` | Shows global packages. |
| `npm explain <package>` | Explains why a package exists. |
| `npm audit` | Checks for security issues. |
| `npm audit fix` | Fixes vulnerabilities automatically. |

### Examples

```bash
npm list
npm audit
npm audit fix
```

---

# 6. The Nuclear Option (Fix Broken npm)

Use this when npm breaks badly.

## Step 1: Clear npm cache

```bash
npm cache clean --force
```

## Step 2: Remove dependencies and lock file

### Mac/Linux

```bash
rm -rf node_modules package-lock.json
```

### Windows PowerShell

```powershell
Remove-Item -Recurse -Force node_modules, package-lock.json
```

## Step 3: Reinstall dependencies

```bash
npm install
```
